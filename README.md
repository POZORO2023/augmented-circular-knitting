# Augmented-circular-knitting
Open-source project exploring how to augment a hobby circular knitting machine with digital control, Arduino-based electronics and 3D-printed components.

## About the project

This project explores how an existing hobby circular knitting machine can be augmented with digital technology.

Building on a prototype developed by a previous student team, we are investigating how Arduino-based electronics and 3D-printed components can add digital control and automated yarn switching to a conventional circular knitting machine.

## Project goals

Our goal is to develop a more accessible and reliable augmentation of the existing machine and document the process as an open-source project.

We want to help makers adapt their own hobby knitting machines without requiring extensive knowledge of electronics or programming.

## Repository contents

- `hardware/` — 3D-printable components and mechanical designs
- `electronics/` — Arduino code, electronics and wiring
- `docs/` — Documentation, assembly instructions and test results

## Project status

The prototype is under development. Components and documentation will be added and updated as they are tested.

**Note:** Not all components or instructions are final. Please check the documentation before attempting to reproduce the prototype.
